Libraries Used
==============

Major libraries and tools used by the Soju platform (project homepages).
For licenses of assets we ship in-repo, see ``README.md`` at the repository root.

Web
---

- `Svelte <https://svelte.dev/>`_
- `SvelteKit <https://kit.svelte.dev/>`_
- `Vite <https://vitejs.dev/>`_
- `Pico CSS <https://picocss.com/>`_
- `Vitest <https://vitest.dev/>`_
- `Prettier <https://prettier.io/>`_

Backend / AI
------------

- `FastAPI <https://fastapi.tiangolo.com/>`_
- `Uvicorn <https://www.uvicorn.org/>`_
- `Pydantic <https://docs.pydantic.dev/>`_
- `HTTPX <https://www.python-httpx.org/>`_
- `edge-tts <https://github.com/rany2/edge-tts>`_
- `Ollama <https://ollama.com/>`_ (optional local AI runtime)
